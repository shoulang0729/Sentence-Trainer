# 06. データモデル

> 論理データモデル（実装非依存）。物理設計（DB種別・スキーマ）は技術選定後に確定する（[07](07-技術・プラットフォーム検討.md)）。

## 6.1 主要エンティティ

| エンティティ | 説明 |
|--------------|------|
| User | 学習者アカウント |
| Language | 学習対象言語（まず中国語）。多言語拡張の基点 |
| Sentence | ユーザーが登録した例文（中国語・訳・ピンイン・重要単語など）。学習コンテンツの最小単位 |
| Keyword | センテンス内の重要単語（意味・解説の表示対象） |
| Card | User × Sentence の学習状態。SRS（間隔反復）の管理単位 |
| ReviewLog | 1回のトレーニング（読み＋自己評価）の記録 |
| StudySession | 1回の学習セッション |
| Tag | センテンスの分類ラベル |
| Group | 共有・学習状況シェアのための小規模グループ |
| Share | 共有（センテンス/まとめ）の単位と公開範囲 |
| UserSetting | ユーザーごとの学習・表示・公開設定 |

## 6.2 エンティティ関連（概念ER）

```
User 1 ──< Sentence            (Sentence は登録した User に属する)
User 1 ──< Card >── 1 Sentence (学習状態は User×Sentence ごと)
User 1 ──< StudySession
User 1 ──< ReviewLog >── 1 Card
Sentence 1 ──< Keyword         (重要単語。任意・0個以上)
Sentence >──< Tag              (多対多)
Language 1 ──< Sentence
User >──< Group  (中間表 GroupMember: 役割・参加日)
Group 1 ──< Share / Sentence共有
Share >── Sentence(または「まとめ」単位)
User 1 ── 1 UserSetting
```

## 6.3 主要フィールド（論理）

### User
- id, email（任意/匿名対応）, displayName, createdAt, authProvider（`要検討`）

### Language
- id, code（例: `zh`）, name, script（簡体/繁体, `要検討`）

### Sentence（ユーザー登録コンテンツ）
- id, ownerUserId, languageId
- text（中国語原文, 必須）
- translation（日本語訳, 必須）
- pinyin（ピンイン, 任意/自動生成）
- audioUrl（音声, 任意/TTS生成）
- notes（メモ・補足）
- sourceShareId（共有から取り込んだ場合の出所, 任意）
- createdAt, updatedAt

### Keyword（重要単語 = 意味・解説の表示対象）
- id, sentenceId
- word（重要単語）
- position（センテンス内の位置/範囲。ハイライト用）
- pinyin（任意）, meaning（語義）, explanation（解説・補足）

### Card（User × Sentence の学習状態 = 間隔反復の核）
- id, userId, sentenceId
- state（new / learning / review / lapsed）
- dueAt（次回出題日時 = 「忘れた頃」を決める）
- interval, easeFactor（SM-2系）, repetitions, lapses
- lastReviewedAt
- （FSRS採用時は stability / difficulty を保持, `要検討`）

### ReviewLog
- id, userId, cardId, reviewedAt
- rating（もう一度/難しい/できた/簡単 等。自己評価）
- shownAids（表示したトグル: ピンイン/意味/解説。任意の記録）, durationMs

### StudySession
- id, userId, startedAt, endedAt, cardsStudied, correctCount

### Tag
- id, ownerUserId, name

### Group / GroupMember
- Group: id, name, ownerUserId, createdAt
- GroupMember: groupId, userId, role（owner/member）, joinedAt
- 学習状況シェアの単位。公開粒度は UserSetting / Share 設定で制御。

### Share
- id, ownerUserId, scope（private / link / group）, targetGroupId（任意）
- 共有対象: Sentence（複数）または「まとめ」
- 取り込み時は取り込み側で新規 Card（state=new）を生成（学習状態はコピーしない）。

### UserSetting
- userId, newPerDay, reviewLimit, autoplayAudio, playbackRate, theme, notificationTime, uiLanguage
- 各トグルの既定表示: showPinyinByDefault, showMeaningByDefault, showKeywordByDefault
- shareVisibility（学習状況の公開粒度: 非公開 / 学習量のみ / 正答率含む 等）

## 6.4 設計上の指針

- **コンテンツ（Sentence/Keyword）** と **学習状態（Card/ReviewLog）** を分離。
  - 共有・取り込みやアルゴリズム変更が学習履歴を壊さないようにするため。
- **重要単語（Keyword）を独立エンティティ**にし、ハイライト位置・複数語・解説に対応（任意）。
- **間隔反復**は Card の dueAt / 間隔系フィールドで表現。アルゴリズムは差し替え可能に。
- **共有**は「コンテンツの複製/参照」と「学習状態」を切り離す。取り込み側は new から開始。
- **学習状況シェア**は集計値（学習量・正答率・ストリーク）を公開粒度に応じて参照させる。
- **多言語拡張**: Language を第一級エンティティとして参照。
- **オフライン同期**を見据え、各レコードに updatedAt / 同期識別子を持たせる（`Should`）。

## 6.5 データ量の見積り（初期）

- ユーザー登録センテンス: 1人あたり数百〜数千件想定。
- Card / ReviewLog: 学習量に応じ最も増加（記録・統計の元データ）。
- 音声アセット: TTS生成分を保持（重複生成を避けキャッシュ）。
