# 06. データモデル

> 論理データモデル（実装非依存）。物理設計（DB種別・スキーマ）は技術選定後に確定する（[07](07-技術・プラットフォーム検討.md)）。

## 6.1 主要エンティティ

| エンティティ | 説明 |
|--------------|------|
| User | 学習者アカウント |
| Language | 学習対象言語（英語など）。多言語拡張の基点 |
| Deck | 例文の集合（コース/教材単位） |
| Sentence | 例文そのもの（原文・訳・音声など）。学習コンテンツの最小単位 |
| Card | User × Sentence の学習状態。SRSの管理単位 |
| ReviewLog | 1回の復習/回答の記録 |
| StudySession | 1回の学習セッション |
| Tag | 例文/デッキの分類ラベル |
| UserSetting | ユーザーごとの学習・表示設定 |

## 6.2 エンティティ関連（概念ER）

```
User 1 ──< Card >── 1 Sentence
User 1 ──< StudySession
User 1 ──< ReviewLog >── 1 Card
Deck 1 ──< Sentence            (Sentence は Deck に属する。多対多にする場合は中間表)
Language 1 ──< Deck
Sentence >──< Tag              (多対多)
User 1 ── 1 UserSetting
```

## 6.3 主要フィールド（論理）

### User
- id, email（任意/匿名対応）, displayName, createdAt
- authProvider（`要検討`）

### Language
- id, code（例: `en`, `ja`）, name, direction

### Deck
- id, languageId, title, description, level（難易度）, isOfficial（既製/ユーザー作）, ownerUserId（マイデッキ時）, createdAt

### Sentence
- id, deckId, text（原文）, translation（訳）, reading/pronunciation（任意）
- audioUrl（音声、TTS生成 or 録音）
- keyTokens（キー語彙・空欄候補, `Should`）
- notes（文法/補足）, difficulty, order

### Card（User × Sentence の学習状態 = SRSの核）
- id, userId, sentenceId
- state（new / learning / review / lapsed）
- dueAt（次回復習日時）
- interval（間隔）, easeFactor（易しさ係数, SM-2系）, repetitions, lapses
- lastReviewedAt
- （FSRS採用時は stability / difficulty を保持, `要検討`）

### ReviewLog
- id, userId, cardId, reviewedAt
- rating（もう一度/難しい/できた/簡単 等）, mode（演習形式）, correct（真偽）, durationMs

### StudySession
- id, userId, startedAt, endedAt, cardsStudied, correctCount, deckId（任意）

### Tag
- id, name

### UserSetting
- userId, newPerDay, reviewLimit, autoplayAudio, playbackRate, theme, notificationTime, uiLanguage

## 6.4 設計上の指針

- **コンテンツ（Sentence/Deck）** と **学習状態（Card/ReviewLog）** を明確に分離する。
  - 既製コンテンツの更新がユーザーの学習履歴を壊さないようにするため。
- **SRSアルゴリズムの差し替え**を可能にするため、Card のアルゴリズム固有フィールドは拡張余地を持たせる。
- **多言語拡張**: Language を第一級エンティティとし、Deck/Sentence から参照する。
- **オフライン同期**を見据え、各レコードに updatedAt / 同期用の識別子を持たせる（`Should`）。

## 6.5 データ量の見積り（初期）

- 既製例文: 数百〜数千文 × 数十デッキ。
- 音声アセット: 例文数に比例（ストレージ計画は [04](04-非機能要件.md) 参照）。
- ユーザー学習データ: Card / ReviewLog は学習量に応じて増加（最も成長する表）。
