# 09. 用語集

本プロジェクトで用いる用語の定義。表記ゆれを防ぎ、認識を統一する。

| 用語 | 定義 |
|------|------|
| 例文 / センテンス（Sentence） | 学習コンテンツの最小単位となる文。原文・訳・音声などを持つ。 |
| カード（Card） | 「ユーザー × 例文」の学習状態を表す単位。SRSの管理対象。 |
| デッキ（Deck） | 例文の集合。コース/教材に相当する。 |
| SRS（Spaced Repetition System） | 間隔反復学習。忘却曲線に沿って復習間隔を最適化する仕組み。 |
| SM-2 | Anki等で使われる代表的なSRSアルゴリズム。易しさ係数(ease)で間隔を調整。 |
| FSRS（Free Spaced Repetition Scheduler） | 記憶の確率モデルに基づく新しめのSRSアルゴリズム。 |
| new（新規） | まだ学習していないカードの状態。 |
| learning（学習中） | 導入直後の短間隔で繰り返している状態。 |
| review（復習） | 間隔を空けて復習する定着フェーズの状態。 |
| lapsed（再学習） | 一度覚えたが忘れて（誤答で）learningに戻った状態。 |
| due（期日到来） | 今日復習すべき状態のカード。 |
| ease factor（易しさ係数） | SM-2系で次回間隔の伸び幅を決める係数。 |
| ストリーク（Streak） | 連続して学習した日数。継続のモチベーション指標。 |
| クローズ（Cloze） | 例文の一部を空欄にして補わせる穴埋め演習。 |
| ディクテーション | 音声を聞いて文を書き取る演習。 |
| 産出（Production） | 訳などを手がかりに自分で文を作るアウトプット演習。 |
| TTS（Text-to-Speech） | テキストから音声を合成する技術。例文の音声生成に利用。 |
| STT（Speech-to-Text） | 音声をテキスト化する技術。発音練習の評価に利用。 |
| PWA（Progressive Web App） | インストール可能でオフライン対応もできるWebアプリ形態。 |
| BaaS（Backend as a Service） | 認証/DB/ストレージ等を提供するバックエンド基盤（Supabase/Firebase等）。 |
| i18n / l10n | 国際化 / 地域化。UI言語と学習対象言語を分離して扱う。 |
| MVP（Minimum Viable Product） | 価値検証のための最小限の機能を備えたプロダクト。 |
| Must / Should / Could | 要件の優先度（MoSCoW）。必須 / 推奨 / 任意。 |
| TBD / 要検討 | 未確定・今後決定する項目を示すマーク。 |
