# 09. 用語集

本プロジェクトで用いる用語の定義。表記ゆれを防ぎ、認識を統一する。

| 用語 | 定義 |
|------|------|
| 例文 / センテンス（Sentence） | 学習コンテンツの最小単位となる中国語の文。原文・日本語訳・ピンイン・重要単語などを持つ。ユーザーが登録する。 |
| 重要単語（Keyword） | センテンス内で覚えたい主要な単語。穴埋め演習の対象になる。 |
| 個別登録 | センテンスを1件ずつ登録する方法。 |
| 一括登録 | CSV/TSV等で複数センテンスをまとめて登録する方法。 |
| カード（Card） | 「ユーザー × センテンス」の学習状態を表す単位。間隔反復の管理対象。 |
| 間隔反復（SRS / Spaced Repetition System） | 忘却に合わせて復習間隔を最適化する仕組み。「**忘れた頃にまた同じ問題が出題される**」を実現する本アプリの中核。 |
| SM-2 | Anki等で使われる代表的なSRSアルゴリズム。易しさ係数(ease)で間隔を調整。実装が容易でMVP向き。 |
| FSRS（Free Spaced Repetition Scheduler） | 記憶の確率モデルに基づく新しめのSRSアルゴリズム。高精度だが複雑。 |
| new（新規） | まだ学習していないカードの状態。 |
| learning（学習中） | 導入直後の短間隔で繰り返している状態。 |
| review（復習） | 間隔を空けて復習する定着フェーズの状態。 |
| lapsed（再学習） | 一度覚えたが忘れて（誤答で）learningに戻った状態。 |
| due（出題期日） | 今日出題すべき状態のカード。「忘れた頃」のタイミング。 |
| ease factor（易しさ係数） | SM-2系で次回間隔の伸び幅を決める係数。 |
| 穴埋め（クローズ / Cloze） | センテンス中の重要単語を空欄にして補わせる演習。 |
| 日本語訳（演習） | 中国語センテンスの意味を日本語で答える/確認する演習。 |
| 発音（演習） | センテンスを音読して評価する演習。録音聞き返し or STT。 |
| ピンイン（拼音） | 中国語の発音をローマ字＋声調記号で表す表音表記。 |
| 声調 | 中国語の音の高低パターン（4声＋軽声）。発音の正誤に関わる。 |
| 簡体字 / 繁体字 | 中国語の字体。本アプリは簡体字を基本（繁体字は要検討）。 |
| 記録・統計 | 登録数・正答率・日別トレーニング量などの学習履歴の蓄積と可視化。 |
| ストリーク（Streak） | 連続して学習した日数。継続のモチベーション指標。 |
| 共有（Share） | 登録したセンテンス/単語を他ユーザーに渡す/取り込む機能。 |
| 学習状況シェア | グループ内で各メンバーの学習量・正答率等を相互に見られる機能。 |
| グループ（Group） | 共有・学習状況シェアのための小規模な集まり（友人・学習仲間・師弟）。 |
| TTS（Text-to-Speech） | テキストから音声を合成する技術。センテンス音声の生成に利用。 |
| STT（Speech-to-Text） | 音声をテキスト化する技術。発音演習の評価に利用（後続）。 |
| PWA（Progressive Web App） | インストール可能でオフライン対応もできるWebアプリ形態。 |
| BaaS（Backend as a Service） | 認証/DB/ストレージ/権限管理等を提供するバックエンド基盤（Supabase/Firebase等）。 |
| ゲーミフィケーション | バッジ・レベル等のゲーム要素。本プロジェクトでは優先度低。 |
| i18n / l10n | 国際化 / 地域化。UI言語（日本語）と学習対象言語（中国語）を分離して扱う。 |
| MVP（Minimum Viable Product） | 価値検証のための最小限の機能を備えたプロダクト。 |
| Must / Should / Could | 要件の優先度（MoSCoW）。必須 / 推奨 / 任意。 |
| TBD / 要検討 | 未確定・今後決定する項目を示すマーク。 |
