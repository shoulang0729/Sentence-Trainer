# 02. ペルソナとユースケース

## 2.1 ターゲットユーザー

例文を通じて外国語（まずは英語）を「使えるレベル」まで身につけたい学習者。
独学者を中心に、スキマ時間で継続的に学習したい層を想定する。

## 2.2 ペルソナ

### ペルソナA: 社会人の学び直し「ケンジ」（32歳）

- 仕事で英語メール/会議が増えてきたが、単語帳は続かなかった。
- 通勤の電車内など**スキマ時間**で学習したい。
- ニーズ: 実務で使える表現を「文ごと」覚えたい。短時間で区切りよく学びたい。

### ペルソナB: 試験対策の学生「ミサキ」（19歳）

- 資格試験（TOEIC/英検など）のスコアを上げたい。
- 例文での文法・語法の運用力と、リスニングを強化したい。
- ニーズ: 出題傾向に沿った例文、間違えた問題の効率的な復習。

### ペルソナC: 多言語学習の趣味人「アレックス」（45歳）

- 趣味で複数言語を学ぶ。自分で例文（マイデッキ）を登録したい。
- ニーズ: 自作デッキ、間隔反復の細かい調整、学習データのエクスポート。

> 初期ターゲットの優先度: **A > B > C**。MVPはペルソナAを主軸に設計する。

## 2.3 利用シーン

- 通勤・通学中のスキマ時間（数分単位、音声中心）
- 就寝前の復習（その日の new + due カードの消化）
- 週末のまとめ学習（新規デッキの追加、弱点の集中演習）

## 2.4 ユーザーストーリー

優先度: `Must`（必須） / `Should`（推奨） / `Could`（任意）

| ID | ユーザーストーリー | 優先度 |
|----|------------------|--------|
| US-01 | 学習者として、例文を意味・音声つきで学びたい。文の中で語彙・文法を理解するため。 | Must |
| US-02 | 学習者として、覚えた例文を最適なタイミングで復習したい。忘れないため。 | Must |
| US-03 | 学習者として、穴埋めや並べ替えで例文を演習したい。記憶を能動的に引き出すため。 | Must |
| US-04 | 学習者として、例文の音声を聞いてディクテーション/発音練習をしたい。聞く・話す力をつけるため。 | Should |
| US-05 | 学習者として、日々の学習量や連続記録（ストリーク）を見たい。継続のモチベーションのため。 | Should |
| US-06 | 学習者として、自分で例文デッキを作成・編集したい。自分の目的に合わせて学ぶため。 | Could |
| US-07 | 学習者として、複数端末で進捗を同期したい。場所を選ばず続けるため。 | Should |
| US-08 | 学習者として、苦手な例文だけを集中的に復習したい。弱点を克服するため。 | Should |
| US-09 | 学習者として、学習リマインダー通知を受け取りたい。習慣化のため。 | Could |
| US-10 | 学習者として、英訳（産出）演習で自分で文を組み立てたい。アウトプット力をつけるため。 | Should |

## 2.5 主要ユースケースフロー（例: 日々の学習）

1. アプリを起動し、今日の「学習」を開始する。
2. 新規カード（new）と復習カード（due）が提示される。
3. 例文を見て/聞いて、演習（穴埋め等）に回答する。
4. 自己評価または自動採点に基づき、SRS が次回復習日を更新する。
5. セッション終了時に、こなした枚数・正答率・ストリークが表示される。
