# 03. 機能要件

機能を優先度 `Must` / `Should` / `Could` で示す。コンテンツは**ユーザー登録型**（既製デッキは持たない）。

> トレーニングの基本方針：**自分で答えを思い浮かべ、答え合わせして自己判断する**（入力式の自動採点はしない）。
> トレーニングは**2モード**:
> - **モードA（中→意味）**: 中国語が出る → 意味を理解できたかを自己判断。
> - **モードB（日→中）**: 日本語が出る → 中国語を書ける（言える）かを確認し、自己判断。
>
> 補助として、**ピンイン／意味／重要単語の解説**を**トグルで表示**できる。**音声読み上げ（TTS）はピンインと一緒に**提供する。
>
> 出題は**1センテンスごとに A → B を連続**で行う（同じ文を「中→意味」→「日→中」の順）。自己評価は**4段階**（もう一度／難しい／できた／簡単）。進捗（間隔反復）は**モードA・Bで別々に管理**する。

## 3.2 F-01 センテンス登録（個別）

ユーザーが1件ずつセンテンスを登録する。本アプリのコンテンツの源泉。

- 入力項目:
  - **中国語センテンス**（必須）
  - **日本語訳**（必須 / モードBの出題＆意味トグルに使う）
  - ピンイン（任意 / 自動生成を検討、`Should`。トグルで表示）
  - 重要単語と意味・解説（任意 / 0個以上。トグルで表示する対象）
  - 音声（任意 / TTS自動生成。ピンインと一緒に提供、`Should`）
  - メモ・タグ（任意）
- 重要単語はセンテンス内の該当箇所と紐づけ、解説表示時にハイライトする。
- 登録後は学習対象（state=new）として学習キューに入る。

## 3.3 F-02 センテンス登録（一括）

複数センテンスをまとめて登録する。

- 入力方式: CSV/TSV 貼り付け or ファイルアップロード（`Must`）。テンプレートを提供。
  - 列の例: `中国語, 日本語訳, ピンイン(任意), 重要単語(任意), 重要単語の解説(任意), タグ(任意)`
- 取り込み前に**プレビュー・検証**（重複・必須項目欠落・形式エラーの検出）。
- 部分的なエラー時は、該当行をスキップ or 修正できる（`Should`）。
- 将来: ピンイン/解説の自動補完（`Could`、AI活用は `要検討`）。

## 3.4 F-03 センテンス提示

- モードに応じて出題面を切り替える:
  - モードA: **中国語**を提示（まず自力で意味を考える）。
  - モードB: **日本語**を提示（中国語を思い浮かべる/書く）。
- 補助情報（ピンイン＋音声 / 意味 / 重要単語の解説）は既定で非表示。F-07 のトグルで表示する。

## 3.5 F-04 間隔反復（SRS）

> ユーザー要望の中核：「**たくさんやると忘れるので、忘れた頃にまた同じ問題が出てくる**」を実現する。

- **モード別に進捗を管理**する。1センテンスにつき、モードA用・モードB用の**2つの間隔反復トラック**を持つ。
  - 各トラックが学習状態（new / learning / review / lapsed）と**次回出題日（dueAt）** を持つ。
- 答え合わせ後の**4段階自己評価**（もう一度／難しい／できた／簡単）でそのトラックの間隔を更新する。
  - もう一度→短い間隔で再提示、難しい→控えめに延長、できた→標準延長、簡単→大きく延長。
- アルゴリズムは既存方式をベースに採用（`要検討`）。候補: SM-2（実装容易・MVP推奨）/ FSRS（高精度）。
- 1日の新規・復習の上限を設定可能（`Should`）。

### 「A→B連続」と「モード別管理」の両立（出題ロジック）
- センテンスは、**モードAまたはモードBのいずれかが due**（または new）になったら今日のキューに入る。
- キューに入ったセンテンスは、**A → B を連続**で実施する（片方しか due でなくても両方行う）。
- それぞれのモードで**個別に4段階評価**し、**各トラックのdueを更新**する。
  - 結果として「意味は分かる（A=簡単で間隔長め）が、書けない（B=もう一度で間隔短め）」のように、モードごとに定着度が分かれて記録される。
- 補足：due でない側のモードも一緒に前倒しで復習される形になる。厳密に独立させたい場合は「due のモードのみ実施」も選択肢（`要検討`）。MVPは「A→B連続・両方実施」を既定とする。

### 1センテンスの実施フロー（A→B連続）
1. **モードA（中→意味）** を実施 → 4段階で自己評価（Aトラックを更新）。
2. 続けて**モードB（日→中）** を実施 → 4段階で自己評価（Bトラックを更新）。
3. 次のセンテンスへ。

## 3.6 F-05 トレーニング・モードA（中 → 意味理解）

1. **中国語センテンス**が提示される（補助情報は既定で非表示）。
2. ユーザーが意味を頭の中で考える。
3. 答え合わせ（意味トグル等で確認。必要に応じてピンイン＋音声／重要単語の解説も）。
4. 「意味を理解できたか」を**4段階で自己評価**し、間隔反復（F-04 / Aトラック）に反映。

## 3.7 F-06 トレーニング・モードB（日 → 中、書けるか）

1. **日本語**が提示される。
2. ユーザーが対応する**中国語を思い浮かべる／書く**。回答方法は2方式（設定で切替）:
   - **想起のみ**: 頭の中で思い浮かべる（軽量・既定）。
   - **テキスト入力**: 中国語IMEで入力する。
3. 答え合わせ（中国語＋ピンイン＋音声を表示）。
   - テキスト入力時は一致/不一致のヒントを参考表示してもよい（`Should`）。
4. 「中国語を書けた（言えた）か」を**4段階で自己評価**し、間隔反復（F-04 / Bトラック）に反映。

> 入力モードでも最終的な間隔反復の更新は**自己評価（4段階）** に基づく。自動採点は補助（ヒント）に留め、表記ゆれ問題を避ける。

## 3.8 F-07 補助トグル（読みの助け）

トレーニング中に、必要なものだけを**トグル（スイッチ）**で表示する。

| トグル | 内容 | 既定 |
|--------|------|------|
| ピンイン＋音声 | ピンイン（声調付き）を表示し、音声読み上げ（TTS）を再生 | OFF |
| 意味 | 日本語訳を表示 | OFF |
| 重要単語の解説 | 重要単語をハイライトし、語義・補足を表示 | OFF |

- **ピンインと音声読み上げはセット**で提供する（ユーザー方針）。
- 各トグルの既定状態（最初から表示するか）は設定（F-15）で変更可能（`Should`）。

## 3.9 F-08 学習記録・統計

> ユーザー要望：「**何個登録して、最近の正答率はいくらで、何月何日にどれくらいトレーニングしたか**」を残す。

- 登録総数、学習済み数、状態別（new/review等）の内訳。
- 直近の**自己評価良好割合**（「できた」の割合など）。全体 / 期間別。
- 日別のトレーニング量（こなしたセンテンス数・学習時間）をカレンダー/グラフで可視化。
- 連続学習日数（ストリーク）（`Should`）。

> 補足：自動採点がないため、「正答率」は**自己評価の良好割合**として定義する（`要検討`）。

## 3.10 F-09 アカウント・同期

- 学習データを保存し、複数端末で同期する（**MVP対象**）。共有（F-10）の前提にもなる。
- 認証方式は `要検討`（メール/パスワード、ソーシャル、匿名→後からリンク）。
- オフライン学習＋オンライン復帰時の同期（`Should`、プラットフォーム依存）。

## 3.11 F-10 共有

- **コンテンツ共有**: センテンス/単語（または「まとめ」単位）を他ユーザーに共有・取り込み。
  - 取り込み時、共有元の学習状態はコピーせず、取り込み側で new から開始する。
- **学習状況シェア**: グループ内で、各メンバーの学習量・自己評価良好割合・ストリーク等を相互に閲覧。
- 想定規模は**小規模グループ**。大規模SNSは対象外。

## 3.12 F-11 弱点復習

- 自己評価が低い / lapse したセンテンスを集めた復習セッションを生成。
- タグ・期間で絞った復習も可能（`Should`）。

## 3.13 F-12 発音トレーニング（いつか実装）

- センテンスを音読し、評価する（録音聞き返し → 将来は STT・声調評価）。
- **将来機能**。コア体験が固まった後のフェーズで実装（[08](08-ロードマップとMVP.md)）。

## 3.14 F-13 ゲーミフィケーション（優先度低）

- ストリーク維持、バッジ、レベル、デイリーゴールなど。優先度は低い。

## 3.15 F-14 リマインダー

- 学習時刻のリマインダー通知（プッシュ/ローカル通知、プラットフォーム依存）。

## 3.16 F-15 設定

- 1日の新規/復習上限、**モードBの回答方式（想起のみ / テキスト入力）**、音声自動再生・速度、各トグルの既定表示、テーマ、通知、（共有時の）公開範囲など。

## 3.17 受け入れ基準（例）

### F-05 / F-06 トレーニング
- [ ] モードAでは中国語が、モードBでは日本語が出題面に表示される。
- [ ] 1センテンスにつき A → B が連続で出題される。
- [ ] モードBの回答方式（想起のみ / テキスト入力）を設定で切り替えられる。
- [ ] 答え合わせ後に**4段階**で自己評価でき、結果がモード別トラックの次回出題日（F-04）に反映される。
- [ ] 補助情報は既定で隠れており、トグルで個別に表示できる。

### F-04 モード別管理
- [ ] 同じセンテンスでも、モードAとモードBで次回出題日が独立して進む。
- [ ] モードA・Bのいずれかが due になると、そのセンテンスが学習キューに入る。

### F-07 補助トグル
- [ ] ピンインを表示すると音声読み上げも利用できる（セット）。
- [ ] 意味・重要単語の解説をそれぞれ独立に表示/非表示できる。

### F-04 間隔反復
- [ ] 「できた」と評価したセンテンスは次回出題日が将来へ後ろ倒しされる。
- [ ] 「もう一度」と評価したセンテンスは短い間隔で再提示される。
- [ ] 一定期間後、忘れた頃（次の due）に同じセンテンスが再出題される。

> 各機能の詳細な受け入れ基準は、実装着手時にチケット単位で具体化する。
