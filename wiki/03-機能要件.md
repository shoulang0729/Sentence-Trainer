# 03. 機能要件

機能を「コア（MVP必須）」「拡張」「将来」に分類する。優先度は `Must` / `Should` / `Could` で示す。

## 3.1 機能一覧（概観）

| 分類 | 機能 | 優先度 | 関連US |
|------|------|--------|--------|
| F-01 | 例文学習（提示・意味・音声） | Must | US-01 |
| F-02 | SRS（間隔反復による復習スケジューリング） | Must | US-02 |
| F-03 | 演習モード（穴埋め/並べ替え/和訳/英訳/ディクテーション/発音） | Must〜Should | US-03,04,10 |
| F-04 | デッキ/コース管理（既製コンテンツ） | Must | US-01 |
| F-05 | 学習進捗・統計・ストリーク | Should | US-05 |
| F-06 | ユーザーアカウント・同期 | Should | US-07 |
| F-07 | マイデッキ（ユーザー作成例文） | Could | US-06 |
| F-08 | 弱点復習・カスタム復習 | Should | US-08 |
| F-09 | リマインダー通知 | Could | US-09 |
| F-10 | 設定（学習量/音声/テーマ等） | Should | - |

---

## 3.2 F-01 例文学習

- 例文（原文）、意味（訳）、読み/発音、音声、必要に応じて文法メモ・補足を提示する。
- 例文に含まれる**キー語彙**をハイライトし、語義を表示できる（`Should`）。
- 1枚＝1例文を基本単位（カード）とする。
- 例文の表示は「意味を隠す→思い出す→答え合わせ」のように能動想起を促す（`Should`）。

## 3.3 F-02 SRS（間隔反復）

- 各カードに学習状態（new / learning / review / lapsed）と次回復習日を持たせる。
- ユーザーの想起成否に応じて次回間隔を更新する。
- アルゴリズムは**既存方式をベース**に採用する（`要検討`）。
  - 候補: SM-2（Anki類似）、FSRS（より新しい確率モデル）。MVPはシンプルな SM-2 系から開始を推奨。
- 1日あたりの新規枚数・復習上限を設定可能にする（`Should`）。
- 「due（今日復習すべき）」カードを抽出して学習キューを生成する。

## 3.4 F-03 演習モード

例文を能動的に処理させる複数の演習形式を提供する。

| モード | 概要 | 入出力 | 優先度 |
|--------|------|--------|--------|
| 意味確認（フラッシュ） | 例文→意味を想起し自己評価 | タップ | Must |
| 穴埋め（クローズ） | 例文の一部を空欄にして入力/選択 | テキスト/選択 | Must |
| 並べ替え | 単語/チャンクを正しい語順に並べる | ドラッグ/タップ | Should |
| 和訳→英訳（産出） | 日本語を見て英文を入力 | テキスト | Should |
| ディクテーション | 音声を聞いて書き取る | テキスト+音声 | Should |
| 発音練習 | 例文を音読し評価 | 音声入力（STT） | Could |

- 採点は「完全一致＋表記ゆれの許容」を基本とし、産出系は柔軟判定（`要検討`：部分一致/AI採点）。
- 誤答は弱点として記録し、F-08 の復習対象にする。

## 3.5 F-04 デッキ/コース管理

- 既製の例文デッキ（レベル別/目的別: 日常会話、ビジネス、試験対策など）を提供する。
- デッキは難易度・トピック・タグで分類・検索できる（`Should`）。
- ユーザーはデッキを「学習中」に追加して進捗管理する。

## 3.6 F-05 進捗・統計

- 日次/週次の学習枚数、正答率、学習時間を可視化する。
- 連続学習日数（ストリーク）と達成バッジ（`Could`）。
- カレンダーヒートマップ等での可視化（`Could`）。

## 3.7 F-06 アカウント・同期

- 学習データを保存し、複数端末で同期する。
- 認証方式は `要検討`（メール/パスワード、ソーシャルログイン、匿名→後からリンク）。
- オフライン学習と後からの同期に対応（`Should`、プラットフォーム依存）。

## 3.8 F-07 マイデッキ（ユーザー生成）

- ユーザーが例文・訳・音声（TTS自動生成）を登録して独自デッキを作る。
- CSV等でのインポート/エクスポート（`Could`）。

## 3.9 F-08 弱点復習

- 誤答が多い/lapse したカードを集めた復習セッションを生成する。
- 特定デッキ・タグに絞った復習も可能（`Should`）。

## 3.10 F-09 リマインダー

- 学習時刻のリマインダー通知（プッシュ/ローカル通知）。
- プラットフォームにより実現方法が異なる（[07](07-技術・プラットフォーム検討.md)）。

## 3.11 F-10 設定

- 1日の新規/復習上限、音声の自動再生、再生速度、テーマ（ライト/ダーク）、表示言語など。

---

## 3.12 受け入れ基準（例: F-02 SRS）

- [ ] 正答したカードは次回復習日が将来へ後ろ倒しされる。
- [ ] 誤答したカードは learning/lapsed となり短い間隔で再提示される。
- [ ] その日の due カードがすべて消化されると「本日完了」が表示される。
- [ ] 1日の新規上限を超えて new カードが提示されない。

> 各機能の詳細な受け入れ基準は、実装着手時にチケット単位で具体化する。
