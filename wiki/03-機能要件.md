# 03. 機能要件

機能を優先度 `Must` / `Should` / `Could` で示す。コンテンツは**ユーザー登録型**（既製デッキは持たない）。

## 3.1 機能一覧（概観）

| 分類 | 機能 | 優先度 | 関連US |
|------|------|--------|--------|
| F-01 | センテンス登録（個別） | Must | US-01 |
| F-02 | センテンス登録（一括） | Must | US-02 |
| F-03 | センテンス学習（提示・ピンイン・意味・音声） | Must | US-03 |
| F-04 | 間隔反復（忘れた頃に再出題するSRS） | Must | US-04 |
| F-05 | 演習（穴埋め / 日本語訳 / 発音） | Must〜Should | US-05,06,07 |
| F-06 | 学習記録・統計（登録数 / 正答率 / 日別学習量） | Should | US-08 |
| F-07 | アカウント・同期 | Must | US-09 |
| F-08 | 共有（センテンス/単語の共有・学習状況シェア） | Should | US-10,11 |
| F-09 | 弱点復習・カスタム復習 | Should | US-12 |
| F-10 | ゲーミフィケーション | Could（優先度低） | US-13 |
| F-11 | リマインダー通知 | Could | US-14 |

## 3.2 F-01 センテンス登録（個別）

ユーザーが1件ずつセンテンスを登録する。本アプリのコンテンツの源泉。

- 入力項目:
  - **中国語センテンス**（必須）
  - **重要単語**（必須 / 1つ以上。穴埋めの対象になる）
  - **日本語訳**（必須）
  - ピンイン（任意 / 自動生成を検討、`Should`）
  - 音声（任意 / TTS自動生成を検討、`Should`）
  - メモ・タグ（任意）
- 重要単語はセンテンス内の該当箇所と紐づけ、穴埋め位置に使う。
- 登録後は学習対象（state=new）として学習キューに入る。

## 3.3 F-02 センテンス登録（一括）

複数センテンスをまとめて登録する。

- 入力方式: CSV/TSV 貼り付け or ファイルアップロード（`Must`）。テンプレートを提供。
  - 列の例: `中国語, 重要単語, 日本語訳, ピンイン(任意), タグ(任意)`
- 取り込み前に**プレビュー・検証**（重複・必須項目欠落・形式エラーの検出）。
- 部分的なエラー時は、該当行をスキップ or 修正できる（`Should`）。
- 将来: 単語リストからのセンテンス自動生成補助（`Could`、AI活用は `要検討`）。

## 3.4 F-03 センテンス学習

- 提示要素: 中国語センテンス、ピンイン、日本語訳、音声、重要単語のハイライト。
- 「意味/ピンインを隠す→思い出す→答え合わせ」の能動想起フローを基本とする（`Should`）。
- 音声は自動再生のオン/オフ、再生速度を設定可能（`Should`）。

## 3.5 F-04 間隔反復（SRS）

> ユーザーの要望の中核：「**たくさんやると忘れるので、忘れた頃にまた同じ問題が出てくる**」を実現する。

- 各センテンスに学習状態（new / learning / review / lapsed）と**次回出題日（dueAt）** を持たせる。
- 想起の成否に応じて次回間隔を更新（正解→間隔を延ばす / 不正解→短い間隔で再提示）。
- アルゴリズムは既存方式をベースに採用（`要検討`）。
  - 候補: SM-2（Anki類似・実装が容易、MVP推奨）/ FSRS（より高精度）。
- 1日の新規・復習の上限を設定可能（`Should`）。
- 「今日出題すべき（due）」を抽出して学習キューを生成する。

## 3.6 F-05 演習（モード）

重要単語を含むセンテンスを能動的に処理させる。

| モード | 概要 | 入出力 | 優先度 |
|--------|------|--------|--------|
| 穴埋め（重要単語） | センテンス中の重要単語を空欄にして補う | テキスト/選択 | Must |
| 日本語訳 | 中国語センテンスの意味（日本語訳）を答える/確認する | 入力 or 自己評価 | Should |
| 発音 | センテンスを音読して評価 | 音声入力（STT）/ 自己評価 | Should |
| 意味確認（フラッシュ） | 提示→想起→自己評価 | タップ | Should |

- 採点: 穴埋めは「正規化＋表記ゆれ許容」。日本語訳・発音は自己評価 or 自動判定（`要検討`）。
  - 発音の自動評価（声調含む）は技術的難度・コストが高いため、まずは**自己評価/録音聞き返し**から開始も可（`要検討`）。
- 誤答は弱点として記録し、F-09 の対象にする。

## 3.7 F-06 学習記録・統計

> ユーザーの要望：「**何個登録して、最近の正答率はいくらで、何月何日にどれくらいトレーニングしたか**」を残す。

- 登録総数、学習済み数、状態別（new/review等）の内訳。
- 直近の正答率（全体 / 期間別 / モード別）。
- 日別のトレーニング量（出題数・学習時間）をカレンダー/グラフで可視化。
- 連続学習日数（ストリーク）（`Should`）。

## 3.8 F-07 アカウント・同期

- 学習データを保存し、複数端末で同期する。共有機能の前提でもある。
- 認証方式は `要検討`（メール/パスワード、ソーシャル、匿名→後からリンク）。
- オフライン学習＋オンライン復帰時の同期（`Should`、プラットフォーム依存）。

## 3.9 F-08 共有

- **コンテンツ共有**: センテンス/単語（または「まとめ」単位）を他ユーザーに共有・取り込み。
  - 共有方法: リンク共有 / グループ内公開 など（`要検討`）。
  - 取り込み時、共有元の学習状態はコピーせず、取り込み側で new から開始する。
- **学習状況シェア**: グループ内で、各メンバーの学習量・正答率・ストリーク等を相互に閲覧。
  - 公開範囲・粒度はプライバシー設定で制御（`Should`）。
- 想定規模は**小規模グループ**（友人・学習仲間・師弟）。大規模SNSは対象外。

## 3.10 F-09 弱点復習

- 誤答が多い / lapse したセンテンスを集めた復習セッションを生成。
- タグ・期間で絞った復習も可能（`Should`）。

## 3.11 F-10 ゲーミフィケーション（優先度低）

- ストリーク維持、バッジ、レベル、デイリーゴールなど。
- **優先度は低い**。コア体験が固まった後に検討（[08](08-ロードマップとMVP.md) 後半フェーズ）。

## 3.12 F-11 リマインダー

- 学習時刻のリマインダー通知（プッシュ/ローカル通知、プラットフォーム依存）。

## 3.13 F-12 設定

- 1日の新規/復習上限、音声自動再生・速度、ピンイン表示有無、テーマ、通知、共有/公開範囲、表示言語など。

## 3.14 受け入れ基準（例）

### F-04 間隔反復
- [ ] 正答したセンテンスは次回出題日が将来へ後ろ倒しされる。
- [ ] 誤答したセンテンスは短い間隔で再提示される。
- [ ] 一定期間「学習しても、忘れた頃（次の due）に同じセンテンスが再出題される」。
- [ ] その日の due をすべて消化すると「本日完了」が表示される。

### F-02 一括登録
- [ ] テンプレート形式のファイル/テキストを取り込み、プレビューできる。
- [ ] 必須項目欠落・形式エラーの行が検出され、ユーザーに示される。
- [ ] 検証を通った行がまとめて学習対象に登録される。

> 各機能の詳細な受け入れ基準は、実装着手時にチケット単位で具体化する。
