# 03. 機能要件

機能を優先度 `Must` / `Should` / `Could` で示す。コンテンツは**ユーザー登録型**（既製デッキは持たない）。

> トレーニングの基本方針：**ひたすら中国語のセンテンスを読む**。穴埋めや日本語訳の入力演習は行わない。
> 読みを助けるために、**ピンイン／意味（日本語訳）／重要単語の解説**を**トグル（スイッチ）で表示**できる。

## 3.1 機能一覧（概観）

| 分類 | 機能 | 優先度 | 関連US |
|------|------|--------|--------|
| F-01 | センテンス登録（個別） | Must | US-01 |
| F-02 | センテンス登録（一括） | Must | US-02 |
| F-03 | センテンス提示（中国語・音声） | Must | US-03 |
| F-04 | 間隔反復（忘れた頃に再出題するSRS） | Must | US-04 |
| F-05 | 読みトレーニング（トグル: ピンイン/意味/重要単語の解説） | Must | US-05,06,07 |
| F-06 | 学習記録・統計（登録数 / 正答率 / 日別学習量） | Should | US-08 |
| F-07 | アカウント・同期 | Must | US-09 |
| F-08 | 共有（センテンス/単語の共有・学習状況シェア） | Should | US-10,11 |
| F-09 | 弱点復習・カスタム復習 | Should | US-12 |

## 3.2 F-01 センテンス登録（個別）

ユーザーが1件ずつセンテンスを登録する。本アプリのコンテンツの源泉。

- 入力項目:
  - **中国語センテンス**（必須）
  - **重要単語**（任意 / 0個以上。トレーニング時に**意味・解説を表示**する対象）
  - **日本語訳**（必須 / トグルで表示する意味）
  - ピンイン（任意 / 自動生成を検討、`Should`。トグルで表示）
  - 重要単語の意味・解説（任意 / 単語ごとに登録。自動補完を検討、`Should`）
  - 音声（任意 / TTS自動生成を検討、`Should`）
  - メモ・タグ（任意）
- 重要単語はセンテンス内の該当箇所と紐づけ、解説表示時にハイライトする。
- 登録後は学習対象（state=new）として学習キューに入る。

## 3.3 F-02 センテンス登録（一括）

複数センテンスをまとめて登録する。

- 入力方式: CSV/TSV 貼り付け or ファイルアップロード（`Must`）。テンプレートを提供。
  - 列の例: `中国語, 日本語訳, 重要単語(任意), 重要単語の解説(任意), ピンイン(任意), タグ(任意)`
- 取り込み前に**プレビュー・検証**（重複・必須項目欠落・形式エラーの検出）。
- 部分的なエラー時は、該当行をスキップ or 修正できる（`Should`）。
- 将来: 単語リストからのセンテンス自動生成補助、ピンイン/解説の自動補完（`Could`、AI活用は `要検討`）。

## 3.4 F-03 センテンス提示

- 既定では**中国語センテンスのみ**を提示する（まず自力で読む）。
- 音声再生（TTS）でお手本の読みを確認できる（`Should`）。
- 補助情報（ピンイン/意味/重要単語の解説）は既定で非表示。F-05 のトグルで表示する。

## 3.5 F-04 間隔反復（SRS）

> ユーザーの要望の中核：「**たくさんやると忘れるので、忘れた頃にまた同じ問題が出てくる**」を実現する。

- 各センテンスに学習状態（new / learning / review / lapsed）と**次回出題日（dueAt）** を持たせる。
- 読んだ後の**自己評価**（読めた／意味が分かった度合い）に応じて次回間隔を更新する。
  - 例: 「もう一度／難しい／できた／簡単」。できた→間隔を延ばす、もう一度→短い間隔で再提示。
- アルゴリズムは既存方式をベースに採用（`要検討`）。
  - 候補: SM-2（Anki類似・実装が容易、MVP推奨）/ FSRS（より高精度）。
- 1日の新規・復習の上限を設定可能（`Should`）。
- 「今日出題すべき（due）」を抽出して学習キューを生成する。

## 3.6 F-05 読みトレーニング（コア）

> トレーニングは**中国語センテンスを読む**ことが中心。入力式の演習（穴埋め・日本語訳の記述）は行わない。

### トレーニングの流れ
1. 中国語センテンスが提示される（既定では補助情報は非表示）。
2. ユーザーが**自力で読む**（黙読 or 音読。音読の良し悪しは自己判断）。
3. 必要に応じて**トグル**で補助情報を表示し、確認する。
4. 読めた度合いを**自己評価**し、間隔反復（F-04）に反映する。
5. 次のセンテンスへ。これをひたすら繰り返す。

### トグル（スイッチ）で表示できる補助情報
| トグル | 内容 | 既定 |
|--------|------|------|
| ピンイン表示 | センテンスのピンイン（声調付き）を表示 | OFF |
| 意味表示 | 日本語訳を表示 | OFF |
| 重要単語の解説 | 重要単語をハイライトし、語義・補足を表示 | OFF |
| 音声 | お手本の読み（TTS）を再生 | 任意 |

- トグルの既定状態（最初から表示するか）は設定で変更可能（`Should`）。
- 「まず自力で読む → 分からなければトグルで確認」という能動想起の流れを推奨。
- 音読してお手本音声と聞き比べる使い方も可能（発音の自動評価は行わない）。

## 3.7 F-06 学習記録・統計

> ユーザーの要望：「**何個登録して、最近の正答率はいくらで、何月何日にどれくらいトレーニングしたか**」を残す。

- 登録総数、学習済み数、状態別（new/review等）の内訳。
- 直近の**自己評価ベースの正答率**（「できた／簡単」の割合など）。全体 / 期間別。
- 日別のトレーニング量（読んだセンテンス数・学習時間）をカレンダー/グラフで可視化。
- 連続学習日数（ストリーク）（`Should`）。

> 補足：穴埋め等の自動採点がないため、「正答率」は**自己評価の良好割合**として定義する（`要検討`）。

## 3.8 F-07 アカウント・同期

- 学習データを保存し、複数端末で同期する。共有機能の前提でもある。
- 認証方式は `要検討`（メール/パスワード、ソーシャル、匿名→後からリンク）。
- オフライン学習＋オンライン復帰時の同期（`Should`、プラットフォーム依存）。

## 3.9 F-08 共有

- **コンテンツ共有**: センテンス/単語（または「まとめ」単位）を他ユーザーに共有・取り込み。
  - 共有方法: リンク共有 / グループ内公開 など（`要検討`）。
  - 取り込み時、共有元の学習状態はコピーせず、取り込み側で new から開始する。
- **学習状況シェア**: グループ内で、各メンバーの学習量・自己評価良好割合・ストリーク等を相互に閲覧。
  - 公開範囲・粒度はプライバシー設定で制御（`Should`）。
- 想定規模は**小規模グループ**（友人・学習仲間・師弟）。大規模SNSは対象外。

## 3.10 F-09 弱点復習

- 自己評価が低い / lapse したセンテンスを集めた復習セッションを生成。
- タグ・期間で絞った復習も可能（`Should`）。

## 3.11 F-10 ゲーミフィケーション（優先度低）

- ストリーク維持、バッジ、レベル、デイリーゴールなど。
- **優先度は低い**。コア体験が固まった後に検討（[08](08-ロードマップとMVP.md) 後半フェーズ）。

## 3.12 F-11 リマインダー

- 学習時刻のリマインダー通知（プッシュ/ローカル通知、プラットフォーム依存）。

## 3.13 F-12 設定

- 1日の新規/復習上限、音声自動再生・速度、各トグルの既定表示（ピンイン/意味/解説）、テーマ、通知、共有/公開範囲、表示言語など。

## 3.14 受け入れ基準（例）

### F-05 読みトレーニング
- [ ] 既定では中国語センテンスのみが表示され、補助情報は隠れている。
- [ ] ピンイン／意味／重要単語の解説を、それぞれ独立したトグルで表示・非表示できる。
- [ ] 重要単語が登録されている場合、解説表示時に該当箇所がハイライトされる。
- [ ] 読んだ後に自己評価でき、その結果が次回出題日（F-04）に反映される。

### F-04 間隔反復
- [ ] 「できた／簡単」と評価したセンテンスは次回出題日が将来へ後ろ倒しされる。
- [ ] 「もう一度」と評価したセンテンスは短い間隔で再提示される。
- [ ] 一定期間後、忘れた頃（次の due）に同じセンテンスが再出題される。

### F-02 一括登録
- [ ] テンプレート形式のファイル/テキストを取り込み、プレビューできる。
- [ ] 必須項目欠落・形式エラーの行が検出され、ユーザーに示される。
- [ ] 検証を通った行がまとめて学習対象に登録される。

> 各機能の詳細な受け入れ基準は、実装着手時にチケット単位で具体化する。
